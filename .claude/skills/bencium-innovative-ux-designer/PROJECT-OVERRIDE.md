# Project override for `bencium-innovative-ux-designer`

The owner of this project (Aksh) decided to use this skill **with its restrictive rules lifted**. This file is the record of that
decision; the vendored `SKILL.md` is left unmodified so the difference stays visible.

## Waived for this project
- "No contemporary visual references": looking at other design work, design systems, and the other vendored skills is allowed.
- "Round one is typography only", "no shapes, effects, gradients, imagery, motion, canvas".
- "Never create SVG" (inline SVG and generated vector art are allowed where they help).
- The ten-direction A to J ritual, the human-only visual judgement rule, and the explicit "lock" protocol.
- "Do not open or render the pages yourself": rendering, screenshots and automated visual checks are encouraged.

## Kept (these are the parts worth having)
- **Derive the look from the subject.** The visual language should come from what TRO actually does (a long questionnaire
  fanned out to specialists, checked, and signed off by a person), not from a generic SaaS template.
- **Translate mechanisms, not appearances.** Parallel work, a review gate, a hold for human judgement: those can become
  motion and form. Do not copy another product's layout.
- **Typography carries character.** Type pairing, scale, case and spacing are designed on purpose.
- **Accessibility and recoverability are fixed boundaries**: contrast, keyboard access, visible focus, `prefers-reduced-motion`.
- **Honesty.** No invented claims, numbers or testimonials on the page.
